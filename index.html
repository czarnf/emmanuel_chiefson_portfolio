05 / Case Study

FlowCast — NHS Patient Flow Prediction

AI-powered system to predict patient flow bottlenecks before they cascade. Being built as Global Talent visa evidence.

Phase 01 — Discovery
Mapping the Problem Space
Identified that reactive patient flow management causes significant delays per bed decision. Mapped ward-level bottlenecks across UHBW sites, informed by direct frontline experience.
Phase 02 — Architecture
Designing the ML Pipeline
Designed a time-series forecasting system using historical admission, discharge, and transfer data. Cloud-native architecture on AWS with real-time inference endpoints.
Architecture
AWS SageMaker → Lambda → API Gateway → React + D3 Dashboard
Phase 03 — Build
Model Training & Clinical Alignment
Training prediction models against anonymised patient flow data. Iterating with clinical stakeholders to calibrate alert thresholds aligned with ward decision-making rhythms.
Phase 04 — Target
