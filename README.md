# emmanuel_chiefson_portfolio (retired)

This repo no longer holds a site. It only keeps the address `emmanuel-chiefson-portfolio.vercel.app` working.

`vercel.json` passes every request through to the current portfolio, which is built from [czarnf/portfolio-v2](https://github.com/czarnf/portfolio-v2). Visitors stay on this address and always see the latest version.

Edit the portfolio in `portfolio-v2`, not here. The previous plain-HTML site (March 2026) is in this repo's git history.
